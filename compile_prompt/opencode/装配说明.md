# opencode 装配说明（standalone skill）

目标是生成一个独立的 opencode skill：`topdown-orchestration`。它不生成 agent，可被任意 agent 触发。

## 输入

- `source_prompt/README.md` 及其全部源文件；
- `compile_prompt/产物定义.md`；
- `compile_prompt/验收.md`。

## 步骤

1. 读 `source_prompt/README.md` 与全部源文件，建立整体理解。
2. 生成 `build/opencode/skills/topdown-orchestration/SKILL.md`：
   - YAML frontmatter：`name: topdown-orchestration`；`description` 写触发条件，不写实现。
   - 正文：输入/输出边界、四环节摘要、关键不变量、references 索引。
3. 把源文件复制到 `references/`，保留文件名与渐进披露；正文只放最小高信号。
4. 不生成 agent；skill 默认对所有 agent 可见。
5. 生成 `build/opencode/使用指引.md`，按 `产物定义.md` 的“使用指引”一节写安装、卸载、更新与验证。
6. 按 `验收.md` 跑无上下文对照实验，报告结果。

## description 草稿

> 当已澄清的复合/复杂需求需要自顶而下分解为目标树、匹配能力、处理缺口并产出编排文档时使用；不负责澄清需求，也不负责执行。

## 约束

- 不修改 `source_prompt/`；产物落在 `build/opencode/`。
- 不把四环节压平成一段；正文摘要，细节进 references。
- 保留“能力匹配”词汇；不得写成“技能检索”。
- 保留每一层目标可判定、部分覆盖带残余缺口、缺口显式、调用实例单父（允许 1:N）、依赖带类型、框架止于编排等不变量。
