# 质量与验收

## 编排文档自检

- **目标层级**：根与中间节点可判定；叶子有完成条件；无孤儿或重复；改述稳定。
- **能力匹配**：每个叶子有完整候选、部分候选 + 残余缺口，或缺口；候选有适用条件与关系类型；无无关或伪造候选。
- **缺口**：挂目标坐标；记录类别（目标不清/能力缺失/平台或权限限制）与知识/方法/工具/约束之一；含证据、处置出口与停止条件；可回流。
- **编排**：每个调用实例有唯一目标父节点（允许 1:N）；依赖标注端点与类型（层级/前置/产物/门禁）并可追溯；跨目标互斥/资源竞争记入调用间约束；可审计；框架不执行、不校验。

## 验收点

| 验收点 | 判据 |
|---|---|
| `leaf_goal_complete` | 目标层级存在；每个叶子目标有完成条件；无孤儿目标 |
| `restatement_stable` | 两份等价需求得到等价的目标与父子关系 |
| `match_or_gap` | 每个叶子目标有完整候选、部分候选 + 残余缺口，或缺口；无匹配不返回伪造能力 |
| `gap_traceable` | 缺口记录包含目标坐标、类别、知识/方法/工具/约束类型、证据、处置出口与停止条件 |
| `every_skill_has_target` | 每个调用实例有唯一目标父节点；允许 1:N；无孤儿 |
| `order_justified` | 依赖含端点、类型（层级/前置/产物/门禁）与依据；调用间约束显式 |
