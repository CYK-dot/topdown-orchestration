# 术语与概念

| 术语 | 定义 |
|---|---|
| 目标树 | 以目标—子目标层级组织的树；根是原始目标，叶子是可直接匹配能力或验收的子目标。每一层节点都必须可判定。 |
| 能力匹配 | 把叶子目标映射到可调用能力，返回候选或缺口；能力如何组织、如何匹配由上层决定。 |
| 能力组织 | 能力的分类与分层方式，如技能、知识、布鲁姆六维；不是框架内建。 |
| 能力缺口 | 某个叶子目标没有可用能力；记录目标坐标、缺失类型与处置出口。 |
| 编排文档 | 框架的产物，包含目标层级、目标—技能绑定、技能调用编排。 |
| 目标—技能绑定 | 每个技能调用挂在具体目标节点下，并记录选择理由与依赖。 |
| 场景机制层 | 场景内部承载机制绑定的部分；可特化分解、匹配、编排规则，但不改变框架不变量。 |
