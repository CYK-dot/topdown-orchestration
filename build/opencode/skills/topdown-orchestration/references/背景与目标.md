# 背景与目标

## 问题

单反射弧技能调用有两类失败：

- **启动失败**：缺少可复用能力，且无法定位缺什么。
- **技能混用性对接失败**：多个技能被部分激活，缺少目标层面的优先/从属裁定，产出局部合理但整体不可追责。

## 目标

把“要做什么”与“会做什么”分开：

1. 在目标空间中自顶而下分解，形成目标树；
2. 对叶子目标做能力匹配；
3. 对缺口做显式处理；
4. 按目标层级编排并记录绑定，产出编排文档。

## 边界

- 输入：已澄清的标准化需求；澄清不在框架内。
- 输出：编排文档；执行、校验、交付不在框架内。
- 框架是微内核：只规定稳定骨架与判据；领域分解模板、能力组织与匹配策略由场景/上层提供。
