# 使用指引：把 `topdown-orchestration` 假安装到 opencode 全局

本目录是构建产物，核心是一个 standalone skill：

```text
build/opencode/skills/topdown-orchestration/
  SKILL.md
  references/
```

安装方式是把 **skill 目录**以软链接或目录联接放进 opencode 全局 skills 目录——本体仍留在 `build/opencode/`，全局目录里只是链接。

## 目标目录

| 平台 | opencode 全局 skills 目录 |
|---|---|
| Linux / macOS | `~/.config/opencode/skills` |
| Windows | `%USERPROFILE%\.config\opencode\skills` |

## 安装（热插）

`<SRC>` 为 `build/opencode/skills/topdown-orchestration` 的绝对路径，`<DST>` 为全局 skills 目录。

### Linux / macOS

```sh
SRC=/path/to/topdown-orchestration/build/opencode/skills/topdown-orchestration
DST=~/.config/opencode/skills
mkdir -p "$DST"
ln -s "$SRC" "$DST/topdown-orchestration"
```

### Windows（目录联接，通常不需要管理员）

```bat
set SRC=C:\path\to\topdown-orchestration\build\opencode\skills\topdown-orchestration
set DST=%USERPROFILE%\.config\opencode\skills
if not exist "%DST%" mkdir "%DST%"
mklink /J "%DST%\topdown-orchestration" "%SRC%"
```

> 也可用 `mklink /D` 创建目录符号链接；它通常需要开发者模式或管理员权限。`/J` 创建目录联接，通常无需管理员。

## 卸载（热拔）

只删除全局目录中的链接，`build/opencode/` 本体保留：

```sh
rm ~/.config/opencode/skills/topdown-orchestration
```

```bat
rmdir "%USERPROFILE%\.config\opencode\skills\topdown-orchestration"
```

删除后 skill 不再可见；重新创建链接即恢复。配置或技能变更后使用 `/reload`；新会话也会重新加载。

## 更新

因为链接指向 `build/opencode/`，改源后重新编译即可更新 skill 内容，无需重新建链接。只有 skill 改名或目录结构变化时，才需要删除并重建链接。

## 验证

1. 新开一个 opencode 会话或在 TUI 执行 `/reload`。
2. skills 列表中出现 `topdown-orchestration`。
3. 输入一个已澄清的复合需求，skill 应触发并输出编排文档；简单直接任务不应触发。
4. 删除链接并重载后，该 skill 应消失。
