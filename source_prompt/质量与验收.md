# 质量与验收

## 编排文档自检

- **目标层级**：根与中间节点可判定；叶子有完成条件；无孤儿或重复；改述稳定。
- **能力匹配**：每个叶子有候选或缺口；候选有适用条件与冲突；无无关或伪造候选。
- **缺口**：挂目标坐标；含缺失类型与处置出口；可回流。
- **编排**：每个技能调用有目标父节点；顺序与依赖可追溯；可审计；框架不执行、不校验。

## 验收点

| 验收点 | 判据 |
|---|---|
| `leaf_goal_complete` | 目标层级存在；每个叶子目标有完成条件；无孤儿目标 |
| `restatement_stable` | 两份等价需求得到等价的目标与父子关系 |
| `match_or_gap` | 每个叶子目标有能力候选或缺口；无匹配不返回伪造能力 |
| `gap_traceable` | 缺口记录包含目标坐标、缺失类型与处置出口 |
| `every_skill_has_target` | 每个技能调用有目标父节点；无孤儿技能 |
| `order_justified` | 先后与依赖可追溯到目标层级、能力前置条件或产物依赖 |
