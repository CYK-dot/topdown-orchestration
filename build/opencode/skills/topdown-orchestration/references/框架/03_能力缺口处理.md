# 能力缺口处理

**职责**：把“没有可用能力”转成可定位、可决策的对象。

**输入**：能力缺口（目标坐标、缺失描述）。

**输出**：缺口记录与处置结果。

## 判据

- **显式定位**：缺口挂在具体目标坐标上，说明缺的是知识、方法、工具还是约束。
- **可分类**：区分目标不清、能力缺失、平台或权限限制；不同类别走不同出口。
- **可回流**：缺口能回到目标分解或能力匹配，形成下一轮。
- **不越界**：不替用户补需求，不静默生成“看起来能用”的能力；假设必须标记。
- **可积累**：缺口记录能进入能力维护，成为后续迭代输入。
- **可控**：避免缺口爆炸或无限分解；有停止条件或优先级。

## 输出字段

- 目标坐标
- 缺失类型
- 证据或现象
- 处置出口：补子目标 / 补能力 / 退回澄清
