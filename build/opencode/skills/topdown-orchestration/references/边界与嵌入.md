# 边界与嵌入

## 输入与输出

- 输入：已澄清的标准化需求，以及上层提供的能力组织。
- 输出：编排文档；不执行、不校验、不交付。
- 发现需求不清时退回澄清，不在框架内补问。

## standalone

- 作为一个 skill 被任意 agent 触发。
- 触发条件：已澄清的复合/复杂需求需要目标分解、能力匹配、缺口处理与编排。
- 宿主需提供能力组织；skill 返回编排文档或缺口。

## embedded

- 作为更大认知工程的源域，参与宿主编译。
- 宿主可以改名、改触发、决定放置位置，但必须保留：
  - 四环节边界与顺序；
  - 输入/输出边界；
  - “能力匹配”而非“技能检索”；
  - 每一层目标可判定；
  - 缺口显式、绑定留痕、框架止于编排。
- 宿主不得把四环节压平成一段系统提示词；应保留参考文件与渐进披露。
- 本模块的 `source_prompt` 是唯一事实源；宿主不得复制后各自漂移，应引用源路径与版本。
